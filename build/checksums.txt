# The C compiler for Linux release builds, selected explicitly rather than taken
# from the runner image.
#
# A glibc-linked binary runs on its build-time glibc or newer, never older, so
# whichever compiler builds the artifact decides which systems can start it. Taking
# that from the build image makes it a property nobody chose: the published v1.12.x
# Linux binaries require glibc 2.34, while the configuration that built them names a
# 2.31 image, because the image was retired and the build moved with no change here
# and no signal that the supported platform set had narrowed. Pinning to a specific
# image only defers that, since images are retired on their own schedule.
#
# There is no build-time symptom either way. The build succeeds, the archive is
# well-formed, and the mismatch is visible only by reading the symbol table of the
# binary that was published.
#
# zig cc targets a chosen glibc directly, so the floor is stated here rather than
# inherited. Upstream also publishes a minisign signature per artifact, which is a
# stronger guarantee than a checksum served from the same host as the file.
#
# This compiler is pre-1.0 and ships breaking changes between releases. After any
# bump, re-measure the floor of the resulting binary rather than assuming it
# carries forward:
#
#   objdump -T build/bin/geth | grep -o 'GLIBC_[0-9.]*' | sort -uV | tail -1
#
# version:zig 0.16.0
# https://ziglang.org/download/
# https://ziglang.org/download/0.16.0/

# This is the builder on PPA that will build Go itself (inception-y).
#
# Upstream's note said this version was "fine to be old and full of security
# holes", because it only bootstraps the real toolchain, and that it should not
# be changed unless it became insufficient. It became insufficient: Go states in
# src/cmd/dist/notgo124.go that "Go 1.26 and later requires Go 1.24.6 as the
# minimum bootstrap toolchain", and the previous pin here was 1.19.6, which
# cannot build the toolchain this project now targets.
#
# So this is raised to the stated minimum rather than to the current release. A
# bootstrap compiler cannot be the version it builds, and taking the minimum
# keeps the jump as small as the requirement allows. Raise it again only when Go
# raises the minimum again, and check notgo1NN.go in the target toolchain's
# source for the number rather than assuming it tracks the release.
#
# version:ppa-builder 1.24.6
# https://go.dev/dl/
