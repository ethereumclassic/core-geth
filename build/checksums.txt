# This is the builder on PPA that will build Go itself (inception-y).
#
# Upstream's note said this version was "fine to be old and full of security
# holes", because it only bootstraps the real toolchain, and that it should not
# be changed unless it became insufficient. It became insufficient: Go states in
# src/cmd/dist/notgo124.go that "Go 1.26 and later requires Go 1.24.6 as the
# minimum bootstrap toolchain", and the previous pin here was 1.19.6, which
# cannot build the toolchain this project now targets.
#
# So this is raised to the stated minimum rather than to the current release. A
# bootstrap compiler cannot be the version it builds, and taking the minimum
# keeps the jump as small as the requirement allows. Raise it again only when Go
# raises the minimum again, and check notgo1NN.go in the target toolchain's
# source for the number rather than assuming it tracks the release.
#
# version:ppa-builder 1.24.6
